# WhatsApp Link Ops Bot V2.8 FULL MERGED FINAL

نسخة واحدة موحدة تجمع V2.6 وV2.7 كاملتين مع تحديث V2.8: حماية الانضمام اليومية، منع تكرار المجموعة بواسطة Group JID، التنبيهات، الصلاحيات الدقيقة، وأرشفة الرسائل المضغوطة. الترقية **إضافية** وتحافظ على قواعد البيانات والجلسات الحالية عند تشغيل `init_db()`.

## إضافات V2.8

- ثلاثة أوضاع للانضمام: **آمن جدًا** (الافتراضي)، **متوازن** يحافظ على أساس إعداد 30 ثانية/10 روابط/60 دقيقة، و**مخصص مع حماية إجبارية**.
- حد متحرك لكل حساب خلال 24 ساعة، فاصل عشوائي، قفل عامل واحد لكل حساب، وقاطع توقف تلقائي عند `retry_later` أو تكرر الفشل.
- منع محاولة الانضمام إلى المجموعة نفسها للحساب نفسه إذا تغير رابط الدعوة، بواسطة `Group JID` وحالة `duplicate_group` في التقارير.
- عدم إعادة إرسال طلب انضمام ما دام الطلب السابق `pending_approval`.
- مركز تنبيهات لانقطاع الحساب، فشل مصدر Telegram، توقف حماية الانضمام، وارتفاع الفشل، مع منع التنبيه المتكرر.
- صلاحيات مستقلة لكل مشرف: الحسابات، الروابط، التجميع، Telegram، الفحص، الانضمام، الرسائل، المهام، المراقبة، المنتهية، المهمشة، والنظام.
- أرشفة الرسائل القديمة داخل SQLite بصيغة zlib مضغوطة وقابلة للاستعادة، دون حذف نهائي، مع تشغيل يدوي أو يومي وتقارير مهام.
- اختبارات ترحيل وعمل فعلية لـ V2.8 إضافة إلى جميع اختبارات V2.0–V2.7.

التفاصيل الأمنية وحدود ما يمكن ضمانه موثقة في `WHATSAPP_JOIN_SAFETY_AR.md`.

## النسخ الاحتياطي

نسخة مشاركة آمنة:

```bash
./botctl.sh backup
```

نسخة محلية كاملة للاستعادة على نفس جهازك:

```bash
./botctl.sh fullbackup
```

> النسخة المحلية الكاملة قد تحتوي جلسات حساسة. لا تشاركها مع أي شخص.

فحص قاعدة البيانات:

```bash
./botctl.sh dbcheck
```

استعادة قاعدة بيانات بعد إيقاف البوت:

```bash
./botctl.sh stop
./botctl.sh restore-db /path/to/whatsapp_ops.db
./botctl.sh start
```

قبل الاستبدال ينشئ الأمر نسخة `pre_restore` من قاعدة البيانات الحالية.

## إعداد Telethon مرة واحدة

أضف إلى `.env`:

```env
TELEGRAM_API_ID=123456
TELEGRAM_API_HASH=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TELEGRAM_SESSION_PATH=data/telegram_user
```

بعد ذلك افتح من البوت:

`الروابط والتجميع ← مصادر Telegram ← جلسات Telegram واستخراج جلسة ← استخراج/إنشاء جلسة`

لن يطلب البوت `API_ID` أو `API_HASH` داخل المحادثة ولن يعرضهما. ملف الجلسة يبقى محليًا داخل `data/telethon/`.

المسار القديم التالي ما زال متاحًا كخيار احتياطي فقط:

```bash
source .venv/bin/activate
python telegram_session_login.py
```

لا ترسل كود دخول Telegram أو كلمة مرور 2FA أو ملف الجلسة لأي شخص.
